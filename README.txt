AI Study Buddy  -  วิธีติดตั้งและใช้งาน
=========================================

สิ่งที่ต้องมี (เวอร์ชันออฟไลน์ ใช้ Ollama)
- คอมพิวเตอร์ Windows 10/11 (หรือ Mac)
- โปรแกรม Ollama ติดตั้งแล้วและเปิดอยู่ (ดาวน์โหลดที่ https://ollama.com/download)
- โมเดลที่โหลดไว้แล้ว (พิมพ์ใน PowerShell ครั้งเดียว ต้องต่อเน็ตตอนโหลด):
    ollama pull gemma3:4b
    ollama pull bge-m3
- Python 3.10 ขึ้นไป (ถ้ายังไม่มี ตัวเปิดโปรแกรมจะพยายามติดตั้งให้เอง)
- ไม่ต้องใช้ API key  หลังติดตั้งครั้งแรกเสร็จ ใช้งานได้โดยไม่ต้องต่ออินเทอร์เน็ต

วิธีใช้ (Windows)
1. แตกไฟล์ zip ออกมาเป็นโฟลเดอร์ (คลิกขวา > Extract All) อย่าเปิดจากในไฟล์ zip ตรงๆ
2. ดับเบิลคลิก start.bat
   - ครั้งแรกจะติดตั้งไลบรารีอัตโนมัติ ใช้เวลา 3-5 นาที (ต้องต่อเน็ต)
   - ถ้าขึ้นว่าไม่พบ Python ให้รอให้ติดตั้งเสร็จ แล้วปิดหน้าต่าง และดับเบิลคลิก start.bat ใหม่
3. เบราว์เซอร์จะเปิดหน้าเว็บ AI Study Buddy ขึ้นมาเอง (ถ้าไม่เปิด ให้เข้า http://localhost:8501)
4. วางโน้ตหรืออัปโหลดไฟล์ แล้วกด "สร้างชุดทบทวน"

วิธีใช้ (Mac)
- ดับเบิลคลิก start.command (ถ้า Mac ไม่ยอมเปิด ให้เปิด Terminal แล้วพิมพ์ bash start.sh ในโฟลเดอร์นี้)

วิธีปิดโปรแกรม
- ปิดหน้าต่างสีดำที่เปิดค้างอยู่ (หรือกด Ctrl+C)

ถอนการติดตั้ง
- ลบทั้งโฟลเดอร์ทิ้งได้เลย ไม่มีอะไรกระจายอยู่ที่อื่น
  (ยกเว้นไฟล์ credentials.toml เล็กๆ ในโฟลเดอร์ .streamlit ของบัญชีผู้ใช้ ซึ่งลบได้เช่นกัน)

ข้อควรรู้
- ทุกอย่างทำงานในเครื่องคุณ เนื้อหาไม่ถูกส่งออกอินเทอร์เน็ต
- AI อาจตอบผิด ควรตรวจสอบกับเอกสารต้นฉบับก่อนใช้จริง
- ความเร็วขึ้นกับเครื่อง (ถ้ามีการ์ดจอ NVIDIA จะเร็วขึ้นมาก)
- ความยาวโน้ตที่ใช้ได้ขึ้นกับค่า num_ctx ในแถบด้านซ้าย > ตั้งค่าขั้นสูง
- ถ้าต้องการโมเดลอื่น ให้ ollama pull ชื่อโมเดล แล้วเปลี่ยนชื่อในตั้งค่าขั้นสูง (ต้องเป็นโมเดลที่อ่านภาพได้ ถ้าจะใช้อ่านรูปหรือ PDF สแกน)
- ปุ่มฟังสรุปด้วยเสียงและโหมดค้นเว็บถูกเอาออกในเวอร์ชันนี้ เพราะต้องใช้อินเทอร์เน็ต

แก้ปัญหา
- ขึ้นว่าเชื่อมต่อ Ollama ไม่ได้: เปิดโปรแกรม Ollama (ไอคอนรูปลา) แล้วรีเฟรชหน้าเว็บ
- ขึ้นว่ายังไม่ได้โหลดโมเดล: พิมพ์ ollama pull ตามชื่อที่แจ้งใน PowerShell
- หน่วยความจำไม่พอหรือ error จาก Ollama: ลดค่า num_ctx หรือปิดโปรแกรมอื่นที่ใช้การ์ดจอ
- ติดตั้งไลบรารีไม่สำเร็จ: ตรวจอินเทอร์เน็ต แล้วดับเบิลคลิก start.bat ใหม่
- เข้าหน้าเว็บไม่ได้: ตรวจว่าหน้าต่างสีดำยังเปิดอยู่ และลองเข้า http://localhost:8501
